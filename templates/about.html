SOFTWARE INFORMATION

软件信息

本页用于说明客户端构成、模型部署方式、运行环境与项目文件组织。

Client

客户端组成

  • 桌面壳体：PyWebView 封装本地窗口界面
  • 后端服务：FastAPI 提供页面路由与检测接口
  • 前端页面：HTML、CSS、JavaScript 实现交互与结果展示
  • 检测引擎：Ultralytics YOLO `.pt` 模型完成缺陷识别

Model

模型部署方式

  • 支持加载默认权重文件 `best.pt`
  • 支持在检测页切换用户自选 `.pt` 模型
  • 模型推理在本地完成，不依赖远程接口
  • 检测结果包括标注图、缺陷统计和坐标明细

Environment

运行环境

  • 操作系统：Windows 桌面环境
  • 推荐 Python 环境：3.10
  • 支持 GPU 或 CPU 推理模式
  • 适用于课程设计、论文展示与实验演示

Project

项目文件

  • `templates/`：页面模板
  • `static/`：样式与前端脚本
  • `best.pt`：默认模型权重
  • `PCB_remake/test/images/`：示例测试图像
