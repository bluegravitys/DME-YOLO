Tech Stack

客户端技术栈

采用本地推理加桌面封装方案，兼顾演示效果、交互体验与离线部署能力。

  • 后端服务：FastAPI + Uvicorn
  • 前端渲染：Jinja2 + HTML + CSS + JavaScript
  • 推理引擎：Ultralytics YOLO `.pt` 本地模型
  • 桌面封装：PyWebView + PyInstaller

Runtime

客户端运行能力

本地模型调用 直接读取训练完成的 `.pt` 权重文件，启动后即可执行缺陷检测。
统一窗口控制 提供最小化、全屏切换与关闭按钮，维持统一的桌面客户端风格。
结果可视化输出 输出标注图像、检测摘要、类别分布、坐标明细与缺陷信息。
缺陷类型覆盖 支持缺孔、鼠咬、断路、短路、毛刺和杂铜等 PCB 常见缺陷。
